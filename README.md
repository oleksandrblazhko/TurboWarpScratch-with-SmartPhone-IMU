# TurboWarpScratch with SmartPhone IMU

Керування Scratch-проєктами (TurboWarp) за допомогою фізичних нахилів та прискорень смартфона через мобільний додаток **Phyphox** та локальний Python **WebSocket-сервер**.

---

## 1. Налаштування смартфона

Для зчитування показників акселерометра смартфона:
1. Встановити додаток **phyphox**:
   - Офіційний сайт: https://phyphox.org/
   - Google Play: https://play.google.com/store/apps/details?id=de.rwth_aachen.phyphox&hl=en
2. У списку датчиків обрати категорію **Raw Sensors**:
   - **Acceleration with g** (акселерометр разом із вектором сили тяжіння Землі).
3. Запустити HTTP-сервер віддаленого доступу:
   - Натиснути кнопку меню `...` (верхній правий куток екрана).
   - Обрати пункт **"Allow remote access"**.
   - Підтвердити увімкнення (кнопка **OK**) — система повідомить адресу сервера вигляду `http://192.168.x.x:8080`.
4. Натиснути кнопку запуску вимірювання **▶** (трикутник на верхній панелі).

---

## 2. Налаштування та запуск WebSocket-сервера

Програма `http2websocket.py` опитує HTTP-сервер Phyphox (20 Гц), виконує калібрування і фільтрацію та транслює дані усім підключеним клієнтам через WebSocket.

1. **Запуск програми:**
   ```bash
   python http2websocket.py
   ```
   *За замовчуванням WebSocket відкривається на `ws://localhost:8767`.*
   *За потреби можна вказати інший порт:*
   ```bash
   python http2websocket.py --port 8768
   ```

2. **Автоматичний пошук IP-адреси смартфона:**
   - Під час старту скрипт перевіряє доступність сервера за списком IP-адрес із `config.json` (`server_ips`).
   - Якщо активну адресу знайдено, підключення виконується автоматично, а робоча адреса ставиться на перше місце у списку.
   - Якщо смартфон перейшов в іншу мережу (або список порожній), програма запропонує ввести нову IP-адресу та автоматично збереже її.

3. **Калібрування нейтрального положення (клавіша F1):**
   - Покладіть або зафіксуйте смартфон у базовому робочому положенні.
   - Натисніть **с** (протягом 3 секунд пролунають звукові сигнали і програма зафіксує зміщення нуля).
   - Для завершення роботи програми натисніть **q**.

## 3. Формат даних WebSocket

Клієнти TurboWarp отримують JSON-пакет наступного формату:

```json
{
  "accX": 0.12,
  "accY": -0.45,
  "angle_x": 0.63,
  "angle_y": -2.35
}
```

### Фізичний зміст параметрів:
* **`accX`, `accY`** (м/с²):
  - **Реальне лінійне прискорення**, отримане безпосередньо від датчика Phyphox (*Acceleration with g*).
  - Очищене від зміщення початкового положення (після калібрування F1) та згладжене експоненційним фільтром низьких частот (EMA, $\alpha=0.3$) для усунення тремтіння рук.
  - Використовується для прямого позиціонування координат, розрахунку швидкості та фізичної інерції (наприклад, переміщення ракетки у `6-Ping-Pong-SmartPhone.sb3`).

* **`angle_x`, `angle_y`** (градуси, діапазон $-90^\circ \dots +90^\circ$):
  - **Розраховані кути нахилу смартфона**, обчислені за формулою:
    $$\text{ratio} = \text{clamp}\left(\frac{\text{acc}}{11.0}, -1.0, 1.0\right)$$
    $$\text{angle} = \arcsin(\text{ratio}) \times \frac{180}{\pi}$$
  - Ідеально підходять для обертання спрайтів, нахилу лабіринту та визначення напрямку жестів у дискретних алгоритмах керування.

## 4. Особливості налаштування Scratch (TurboWarp)

Каталог `TurboWarpApplications` містить готові приклади адаптованих ігор (`.sb3`), клонованих із відкритого репозиторія Scratch.

Для роботи використовується середовище **TurboWarp**:
- Веб-версія: https://turbowarp.org/
- Десктоп-версія: https://desktop.turbowarp.org/

### Реалізація взаємодії:
1. Підключено офіційне розширення **WebSocket**.
2. Створено допоміжний спрайт **Controller**, який:
   - підключається до `ws://localhost:8767`;
   - парсить JSON-повідомлення;
   - встановлює значення змінної напрямку `contr_direction` (`left`, `right`, `up`, `down`, `null`).

### Орієнтація смартфона:
Сервер транслює дані для класичного вертикального тримання смартфона. Якщо смартфон розміщено горизонтально:
- Для координат: $x := accY$, $y := accX$.
- Для кутів нахилу: $angle_x := angle_y$, $angle_y := angle_x$.

### Дискретизація керування (стан `null`):
Для ігор, розрахованих на короткочасні дискретні натискання клавіш (наприклад, Тетріс), постійний нахил може викликати безперервне спрацьовування.
Для вирішення цієї проблеми введено проміжний стан `contr_direction = null`:
- Після фіксації дії та завершення кроку змінна скидається в `null`.
- Для повторної дії гравець повинен повернути смартфон у нейтральну зону і нахилити повторно.
